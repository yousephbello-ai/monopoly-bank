# Monopoly Bank

A digital banking system for playing Monopoly.

## Planned features

- One-device mode for managing all players from a single screen.
- Multi-device mode so each player can view their account from their own device.
- One bank administrator with control over player accounts and transactions.
- Player accounts and balances.
- Deposits, withdrawals, transfers, rent, taxes, and bank payments.
- Transaction history and game reset controls.

## Technology

- HTML, CSS, and JavaScript for the web application.
- GitHub Pages for static hosting.
- Firebase for shared multi-device data synchronization.

## Project status

Initial setup. Features will be implemented and tested incrementally.

## Important

This project is intended only for fictional Monopoly game money. It is not a real banking service and must not be used to store or transfer real money.
